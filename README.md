Projektet indeholder flere kode dele:
Python:
  Python koden kan findes i filen dukat2.py som er et bibliotek der indeholder alle funktioner lavet til kontrolleren af systemet.
  For at køre Python koden er det en god ide at kigge i example.ipynb, som er en Jupyter notebook fil der indeholder nødvendige kommandoer der kræves for at køre systemet, denne kode kan direkte anvendes, eller omskrives efter behov
  
C:
  C-koden som køres på en STM32 er at finde i mapperne Core og Inc, her findes c-filerne og h-filerne der er nødvendige for systemet.
